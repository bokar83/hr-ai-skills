# Brevity edit

Say it in fewer words without losing the point. Two jobs: edit a draft, or build a short brief from a topic.

## When to use
- A message, update or memo is longer than the reader will read.
- You need a short brief on a topic for a leader.
- A manager update has the main point buried in the third paragraph.

## When to skip
- The decision itself is still open. Use executive-brief to frame the ask first.
- The text is a policy or legal wording that must stay exact.

## Inputs needed
- Edit mode: the draft.
- Brief mode: a headline or topic, and the facts you have.
- The reader: senior leaders (want the decision and the cost) or front-line managers (want what to do and by when).
- The one thing the reader must remember.

## Steps
1. Pick the mode. If unclear, ask which.
2. If the reader is not stated, ask. Do not guess, because the framing differs.
3. Apply these six rules:
   1. Start with the reader's goal: what is new, useful or urgent for them.
   2. If there is a headline or subject line, keep it under 60 characters, concrete and plain. Do not add new content to do this.
   3. First sentence says what it is and why it matters.
   4. Use everyday words, as if talking in a hallway.
   5. Make it scannable: short paragraphs, bullets where they help, one bolded line for the key point.
   6. Stop when it is clear. Cut anything that repeats.
4. Cut jargon and filler: delve, landscape, robust, synergy, paradigm, leverage (as a verb), in today's fast-paced world, it is important to note. Drop rhetorical question openers. Use periods or commas, not dashes.
5. EDIT MODE: return the shorter draft. Add one line naming the biggest changes only if a point was removed or moved.
6. BRIEF MODE: return exactly three parts. Subhead: one sentence that adds context to the headline. Why it matters: one or two sentences on relevance, without repeating the headline. Data points: up to three bullets, each with its source in brackets. If there is no source, write [SOURCE NEEDED]. If fewer facts were given, use fewer bullets. Never invent a figure.
7. Check the result against the original: nothing added, no meaning changed.

## Quality bar
- Shorter, same meaning, nothing invented.
- The first line works alone.

## Output format
Edit mode: the revised draft, then an optional one-line note of changes. Brief mode: Subhead, Why it matters, Data points.

## If input is missing
Ask for the draft or topic, and the reader.

## Works with
Pairs with executive-brief and employee-comms-draft. Run humanize last if the text still reads machine-written.

## Rules for every skill
- Use only what the user gave. Do not invent facts, quotes, numbers or dates. Write UNKNOWN or [NEED FACT] instead.
- If you are not sure, say so plainly. Never guess to look confident.
- Plain English. No dashes used as punctuation breaks.
- Never send, post or act on anything. Produce drafts for the user to decide on.
